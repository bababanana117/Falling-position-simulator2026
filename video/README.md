# video: 統計風の紹介動画（30 秒）

`wind_climatology_30s.mp4` — 1920×1080、30 fps、音声つき（AAC ステレオ、約 -14 LUFS）。

After Effects 風のポップなモーショングラフィックスで、研究の結果を 30 秒で紹介する。
絵も音もすべてスクリプトで作っているので、素材の権利関係は無い（データの出典は下記）。

## 作り方

```bash
cd research && python ../video/prepare_data.py   # 研究の出力から数字を集める → video/data.json
cd ../video
python music.py                                  # BGM と効果音 → build/audio.wav
python render.py                                 # 映像を描いて音と合わせる（14 並列で約 30 秒）
python render.py --still 12.3 --out a.png        # 1 枚だけ確かめる
```

- `timeline.py` にシーンの区切りと効果音の時刻がある。画面と音の両方がここを読むので、ずれない。
- BGM は 128 BPM・16 小節（= 30.0 秒）。2 小節ずつ 8 シーン。
- フォントは TeX Live の原ノ味角ゴシック（`render.py` の `FONT_DIR`）。

## 構成

| 秒 | シーン | 使った数字 |
|---|---|---|
| 0–3.75 | タイトル | JRA-3Q 2016–2025 |
| 3.75–7.5 | 気球が上がって、割れて、降りる | 落下点 = 全高度の風の足し算 |
| 7.5–11.25 | 冬の上空 12 km の風（棒グラフ） | 北海道 40 / 和歌山 76 / 愛媛 75 m/s |
| 11.25–15 | 北海道・上空 12 km の 1 年（折れ線） | 最大は 10 月前半 53 m/s |
| 15–18.75 | 上空 31 km の風配図 | 7 月後半 94 % / 10 月後半 16 % |
| 18.75–22.5 | 地図：1 月は東へ約 250 km、7 月は南が西向き | 平均落下位置（実寸の矢印） |
| 22.5–26.25 | 壱岐から冬に上げた落下点 | 瀬戸内海か雪のない平野へ 47 %、速い上昇で 62 % |
| 26.25–30 | 締め | 予報は 7 日先まで。計画は、統計風で。 |
