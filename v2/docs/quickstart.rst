==========
まず動かす
==========

必要なのは ``.duckdb`` ファイル 1 つだけです。サーバも設定ファイルも要りません。

この章は ``SELECT`` が読める人向けです。SQL やデータベースが初めてなら、
先に :doc:`basics` を読んでください。

.. code-block:: console

   $ pip install duckdb
   $ python -c "import duckdb; duckdb.connect('jra3q_japan_wind_2016-2025_v2.duckdb', read_only=True)"

コマンドラインから引きたい場合は DuckDB の CLI でも同じことができます。

.. code-block:: console

   $ duckdb -readonly jra3q_japan_wind_2016-2025_v2.duckdb

.. note::

   ``read_only=True`` を付けてください。付けないと DuckDB が書き込みロックを取り、
   同じファイルを別のプロセスから開けなくなります。解析中に Jupyter と CLI の
   両方から触ることは珍しくないので、既定で読み取り専用にしておくと困りません。

格子点を選ぶ
============

打ち上げ地点の緯度経度は、たいてい半端な小数です。一方で、JRA-3Q は **ガウス格子**
なので、緯度は 24.1623、24.5369、24.9115 …… と不等間隔に並んでいます。そのため
``WHERE lat = 33.5`` と書いても、エラーにはならないまま 0 行が返ってきます。

この落とし穴を避けるために、最寄りの格子点を返すマクロを用意してあります。

.. sql-recipe:: 01_nearest_cell.sql
   :caption: 最寄り格子点

格子の間隔はおよそ 35--40 km なので、``distance_km`` は最大でも 27 km 程度に収まります。
それより大きい値が返ったときは、領域の外を指定しています。

1 地点の鉛直プロファイル
========================

``profile_at(緯度, 経度, 月, 前半なら 1 / 後半なら 2)`` は、最寄り格子点の探索まで
済ませたうえで、気球が下から通る順にプロファイルを返します。

.. sql-recipe:: 02_profile.sql
   :caption: 10 月後半、潮岬上空

``dir_from_deg`` は風が **吹いてくる** 向きです。北を 0 度として時計回りに測るので、
270 度は西風、つまり西から東へ流れることを表します。この向きの決め方は
:doc:`datamodel` で詳しく説明します。

``constancy``\ （恒常度）は、ベクトル平均の大きさをスカラー平均で割った値です。1 に
近いほど、その時期の風向が毎回ほぼ同じだったことを意味します。上の表では 200 hPa で
0.95 に達しており、ジェット気流が安定して西から吹いていることが読み取れます。
逆に 850 hPa は 0.12 しかなく、地上付近の風向はこの時期ほとんど定まっていません。

全国の地点を並べる
==================

地点を ``VALUES`` で並べれば、全国を一度に比べられます。

分布を引く
==========

平均値だけでは落下位置のばらつきを出せません。そこで、当てはめ済みの分布を
``fits_at`` でまとめて取り出します。

.. sql-recipe:: 03_fits_at.sql
   :caption: 選ばれた分布とその定数

各行が 1 つの分布の完全な定義です。``speed_family`` が ``weibull_min_loc0`` なら
形状 ``k`` と尺度 ``lambda`` を、``normal`` なら ``mu`` と ``sigma`` を読みます。
どの列を読めばよいかは ``speed_family`` を見れば決まります。

式そのものを受け取る
====================

族ごとに場合分けを書くのが面倒なときのために、定数を埋め込んだ式を文字列で返す
列を用意してあります。

.. sql-recipe:: 04_pdf_rendered.sql
   :caption: 定数を埋め込んだ式
   :limit: 2

``speed_sample`` は逆関数法の式です。一様乱数 :math:`u \in (0,1)` を代入すれば、
その面の風速が 1 つ得られます。

.. sql-recipe:: 13_monte_carlo.sql
   :caption: データベースの中だけでモンテカルロを回す

標本平均が理論平均とおおむね一致しています。つまり、表に入っている定数だけで
分布を再現できています。
