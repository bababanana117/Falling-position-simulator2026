======
用語集
======

.. glossary::
   :sorted:

   DuckDB
      1 つのファイルで完結するデータベース。サーバを立てる必要がなく、
      ``.duckdb`` ファイルを開くだけで使える。大量の行をまとめて集計するのが
      得意で、この配布物の形式になっている。

   SQL
      データベースに問い合わせるための言語。このデータベースを使うのに要る
      のは ``SELECT`` ``WHERE`` ``GROUP BY`` ``JOIN`` ``ORDER BY`` ``LIMIT``
      の 6 つだけ。

   テーブル
      行と列でできた表。列ごとに型が決まっている。このデータベースには 18 ある。

   ビュー
      名前を付けて保存しておいたクエリ。データの複製ではなく、読むたびに元の
      表から計算される。名前が ``v_`` で始まる。

   マクロ
      引数を取れるビュー。``nearest_cell(42.5, 143.4)`` のように地点や時期を
      渡して呼ぶ。このデータベースには 3 つある。

   結合
      2 つの表を共通の列でつなぐこと。SQL では ``JOIN``。番号しか持たない
      ファクト表に、その番号の意味を持つ次元表をつなぐのに使う。

   ファクト表
      測った値そのものを持つ表。行数が多い。名前が ``fact_`` で始まる。

   次元表
      ファクト表が番号で参照している「いつ」「どこ」を定義する表。行数が
      少ない。名前が ``dim_`` で始まる。

   代理キー
      行を一意に指すために振った番号。``cell_id`` ``level_id`` ``timebin_id``
      がそれ。意味を持たないので、緯度や気圧が変わっても番号は変わらない。

   NULL
      値が無いという印。0 とは違う。``circ_sd_deg`` は風向が定まらない面で
      NULL になるので、ばらつきが 0 と読み違えないこと。

   Parquet
      列ごとに圧縮して保存するファイル形式。型が保たれるので、書き出して
      読み直しても数値が変わらない。``COPY ... TO 'x.parquet'`` で出せる。

   JRA-3Q
      気象庁の第 3 次長期再解析。観測を数値予報モデルに同化して作った、
      格子点上の大気の推定値。1947 年から現在までを覆う。このデータベースは
      2016--2025 年の部分を使っている。

   再解析
      過去の観測を、同じ 1 つのモデルと同化手法で作り直したデータ。予報業務で
      使うモデルは年々変わるので、そのままでは長期の比較ができない。再解析は
      その不均一さを取り除くために作られる。観測そのものではない。

   ガウス格子
      球面調和関数を使うモデルが用いる格子。緯度が等間隔ではなく、ガウス・
      ルジャンドル求積の分点に置かれる。このため ``lat = 42.5`` のような
      切りの良い値は格子上に存在しない。

   ジオポテンシャル高度
      重力ポテンシャルを標準重力で割った高度。緯度によって変わる重力を吸収
      するので、気象で広く使われる。幾何高度（実際の距離）とは緯度と高度に
      応じて数十 m から数百 m 違う。

   気圧面
      気圧が一定の面。高度ではなく気圧を鉛直座標に使う。同じ 200 hPa でも、
      冬は夏より 500 m ほど低い位置にある。

   半月ビン
      このデータベースの時期の単位。月の前半（1--15 日）と後半（16 日--月末）に
      分けた 24 区分。週と違って境界が毎年同じ日付に来る。

   恒常度
      ベクトル平均の大きさをスカラー平均で割った値
      :math:`C = |\bar{\mathbf V}| / \overline{|\mathbf V|}`。1 に近いほど、その
      時期の風向が毎回同じだったことを表す。

   平均合成長
      風向を単位ベクトルに直して平均した長さ :math:`\bar R`。0 なら向きが
      ばらばら、1 なら毎回同じ向き。円周統計の基本量で、von Mises の集中度や
      巻き付け正規の幅はここから決まる。

   円周標準偏差
      :math:`\sqrt{-2\ln\bar R}`。角度のばらつきの尺度。:math:`\bar R` が 0.1 を
      下回ると意味を失うので、そのときは NULL にしてある。

   有効標本数
      自己相関を考慮した実質的な標本数
      :math:`n_{\mathrm{eff}} = n(1-r_1)/(1+r_1)`。6 時間ごとの風は互いに
      似ているので、600 本の標本が 600 個の独立な観測に相当するわけではない。

   AIC
      赤池情報量規準 :math:`-2\ln L + 2k`。当てはまりの良さとパラメータ数の
      兼ね合いで族を選ぶ。差が 2 を下回るときは、実質的に区別できないと見なす
      のが慣例。

   ΔAIC
      そのセルで最小の AIC からの差。勝った族は 0 になる。自己相関のぶん
      水増しされているので、``delta_aic_effective`` を見ること。

   von Mises 分布
      円周上の正規分布に当たる分布。密度は
      :math:`e^{\kappa\cos(\theta-\mu)} / (2\pi I_0(\kappa))`。集中度
      :math:`\kappa` が大きいほど向きが揃う。

   巻き付け正規分布
      正規分布を円周に巻き付けた分布。von Mises とよく似た形になるが、閉形式の
      最尤推定量が無いので、このデータベースではモーメント法で推定している。

   Kuiper 統計量
      円周上の適合度統計量 :math:`V = D^+ + D^-`。KS 統計量と違い、角度の原点を
      どこに取っても値が変わらない。

   逆関数法
      累積分布関数の逆関数に一様乱数を代入して、その分布に従う乱数を作る方法。
      Weibull と一様分布は逆関数が閉形式なので、SQL の中だけで実行できる。

   ガウス・コピュラ
      各変数の周辺分布を保ったまま、変数どうしの順位相関を付ける方法。気圧面
      ごとに当てはめた風速分布を、鉛直方向の相関を残して結び付けるのに使う。

   吹いてくる向き
      気象で使う風向の慣習。北を 0 度として時計回りに測り、270 度は西風を表す。
      このデータベースは ``fact_drift.bearing_deg`` を除きこの慣習で統一して
      いる。
